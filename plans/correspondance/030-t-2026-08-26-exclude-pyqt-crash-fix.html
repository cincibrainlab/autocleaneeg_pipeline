Execution Update

The crash reproduced as a native process abort when importing PyQt6.QtCore under the repository's previous dependency pin. The observed message was Incompatible processor. This Qt build requires the following features: neon. This is not a Python exception and cannot be caught by normal try/except ImportError guards once the bad native import starts.

The final minimal bugfix keeps the dependency pin unchanged, sets QT_API=pyqt6 before qtpy imports, keeps launch-only MNE Qt backend setup out of module import, and moves pure metadata parsing helpers into a Qt-free module so metadata tests do not import the full GUI. It also adds a subprocess regression test that imports autoclean.tools.autoclean_exclude, so future hard aborts are caught.

Scope Limits

This fix is scoped to the Exclude PyQt import/crash path. It does not change ICA report behavior, Exclude product behavior, or reprocessing artifact cleanup semantics.
