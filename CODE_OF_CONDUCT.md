# Code of Conduct

## Our Standard

Participation in this project should be respectful, technically honest, and
constructive. Contributors are expected to:

- engage in good-faith technical discussion
- critique ideas and implementations, not people
- avoid harassment, discrimination, or intimidation
- respect different experience levels and backgrounds
- keep bug reports, reviews, and design discussions focused on the work

## Unacceptable Behavior

Examples of unacceptable behavior include:

- personal attacks, insults, or hostility
- harassment or discriminatory language
- repeated bad-faith disruption of issues, reviews, or discussions
- doxxing, threats, or intimidation
- knowingly misrepresenting test results, benchmarks, or security claims

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict
participation for behavior that violates this code of conduct.

## Reporting

Report conduct concerns privately to the maintainers listed in
[`pyproject.toml`](pyproject.toml). Public escalation in GitHub issues should be
reserved for repository work, not interpersonal incidents.
