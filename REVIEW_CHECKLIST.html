Code Deep Dive HIGH PRIORITY

🔍 Understanding Subject ID Extraction Pattern

⚠️ Critical Pattern: This was the key fix that resolved the "unknown_subject" naming issue
Location: Look for this pattern in any mixin file
# Standard pattern (copy this!) subject_id = None if hasattr(self, "config"): config = self.config if "unprocessed_file" in config: subject_id = Path(config["unprocessed_file"]).stem elif "subject_id" in config: subject_id = config["subject_id"] elif "base_fname" in config: subject_id = config["base_fname"] elif "original_fname" in config: subject_id = Path(config["original_fname"]).stem # Fallback if subject_id is None and hasattr(self, "file_path"): subject_id = Path(self.file_path).stem if subject_id is None: subject_id = "unknown"
Why this works: Uses config["unprocessed_file"] as primary key, which is reliably set during import
Search the codebase for where this config key gets populated (likely during import_raw())

💾 Understanding save_stc Parameter

Background: STC files are HUGE (2.3GB for Raw, 78MB per epoch). We made saving them optional.
File: blocks/analysis/source_localization/algorithm.py
Look for: Lines 82-83 where STC saving is conditional:
if config is not None and save_stc: save_stc_to_file(stc, config, stage="post_source_localization")
File: blocks/analysis/source_localization/mixin.py
Check: Parameter default (line 58), config extraction (line 136), and passing to algorithm (line 182)
STC files: 2.3GB, 20,484 vertices, full spatial resolution
ROI files: 3.9MB, 68 channels, regional averages
Decision: Default save_stc=False, recommend convert_to_eeg=True for most use cases

🧩 Understanding Block Architecture

Each block has:
  • manifest.json - Metadata, version, references
  • mixin.py - User-facing interface (inherits into Task)
  • algorithm.py - Core implementation (stateless functions)
  • schema.py - Config validation (Pydantic models)
  • README.md - User documentation
Pick source_localization and follow:
1. User calls self.apply_source_localization() in task
2. Method defined in mixin.py extracts config
3. Mixin calls function in algorithm.py
4. Algorithm returns SourceEstimate object
5. Mixin sets self.stc for downstream blocks
