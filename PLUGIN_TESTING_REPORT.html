Plugin System Architecture

How Plugin Discovery Works

  1. Scan Directories: Check ~/.autoclean/blocks/, ./blocks/, and $AUTOCLEAN_TASK_REGISTRY_PATH/blocks/
  2. Find Python Files: Recursively search for *.py files (excluding __init__.py)
  3. Load Modules: Use importlib.util.spec_from_file_location() for direct file loading
  4. Extract Mixins: Find classes ending with "Mixin"
  5. Add to Inheritance: Append to Task base class after internal mixins
  6. Confirm Loading: Print success message for each loaded plugin

Example Plugin Usage

Creating a Plugin

# ~/.autoclean/blocks/my_custom_plugin.py
from autoclean.calc.preprocessing import some_helper_function

__block_metadata__ = {
    "name": "my_custom",
    "version": "1.0.0",
    "author": "Research Group X"
}

class MyCustomMixin:
    """Add custom processing to pipeline."""

    def my_custom_method(self):
        """Apply custom processing step."""
        # Your implementation using pipeline helpers
        result = some_helper_function(...)
        return result

Using Plugin in Task

from autoclean.core.task import Task

class MyTask(Task):
    def run(self):
        self.import_raw()
        self.my_custom_method()  # Available automatically!
