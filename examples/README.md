# Examples

This directory contains maintained example and template material for the
repository.

## Status Of These Files

- example files here are intentionally kept as reference material
- they are not the canonical install or quick-start path
- they are not treated as the same stability surface as the packaged CLI
- some are illustrative templates rather than ready-to-run end-user workflows

## Current Contents

- `custom_artifact_detector_plugin.py`
  - plugin template showing extension structure

- `amplitude_quality_coach_example.py`
  - illustrative example for quality-coaching workflows

- `event_discovery_example.py`
  - illustrative example for event discovery usage

- `ica_caching_example.py`
  - illustrative example for ICA caching behavior

- `README_PLUGIN_EXAMPLES.md`
  - focused guidance for plugin-oriented examples

## Policy

- keep only examples that still reflect current concepts or extension patterns
- move historical or misleading examples to archive rather than letting them
  silently age in place
- prefer templates and narrowly scoped demos over sprawling pseudo-production
  scripts
