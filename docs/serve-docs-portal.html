What to use when

If you are an operator
  • Open the first-route tutorial if you are starting from zero.
  • Open the edit tutorial when the route already exists and something changed.
  • Open the visual guide first.
  • Use the route screen to inspect, toggle, promote, and sync routes.
  • Think in Draft and Production, not raw queue files.
If you are debugging behavior
  • Open the devlog.
  • Check the route registry under routes/*.yaml.
  • Remember that serve-test.yaml and serve-live.yaml are compiled outputs.
If you are onboarding someone
  • Start with this portal.
  • Send operators to the guide.
  • Send developers to the devlog and branching policy.
