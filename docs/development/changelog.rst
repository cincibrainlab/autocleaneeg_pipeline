Changelog
=========

The canonical project changelog lives in
`docs/CHANGELOG.md <https://github.com/cincibrainlab/autoclean_pipeline/blob/main/docs/CHANGELOG.md>`_.

This page exists to keep the published Sphinx documentation aligned with the
repository layout and to point contributors and users to the maintained release
history source.

Current policy:

- add release notes to `docs/CHANGELOG.md`
- avoid maintaining a second independent changelog in RST form
- use this page as the published pointer rather than a divergent duplicate

Recent release history is recorded in the Markdown changelog above. When the
published docs need more release context, summarize it there and link back to
the canonical file rather than duplicating the full history here.
