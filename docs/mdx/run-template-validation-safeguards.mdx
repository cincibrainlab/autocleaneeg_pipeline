## What changed under the hood

<Steps>

### 1. Centralize identifier validation
`autoclean.utils.template_renderer` now exposes `validate_python_identifier`, a reusable helper that enforces identifier rules and keyword checks across any templated content.【F:src/autoclean/utils/template_renderer.py†L1-L65】

### 2. Guard the wizard entry point
`_wizard_create_task_from_template` delegates to the new validator so wizard flows fail fast with actionable feedback when users supply unsafe class names.【F:src/autoclean/cli.py†L3208-L3258】

### 3. Extend the regression test matrix
Unit tests now cover the happy path, missing template files, malformed template syntax, and identifier validation success/failure, giving confidence that our safeguards stay in place.【F:tests/unit/templates/test_custom_task_template.py†L1-L52】

</Steps>
