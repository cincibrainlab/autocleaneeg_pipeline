## How the change came together

<Steps>

### 1. Capture the baseline
We added helper utilities to collect the active workspace, task file, montage, and input, and render them with Rich tables so the wizard can preview state before touching anything.【F:src/autoclean/cli.py†L2882-L2963】

### 2. Create task bootstrap helpers
Fresh installs need a workspace task to edit. We embedded template-driven creation plus class/filename sanitizers so the wizard can materialize a ready-to-edit task safely.【F:src/autoclean/cli.py†L2965-L3036】

### 3. Orchestrate the wizard flow
The new `cmd_wizard` function wraps workspace selection, task choice/creation, montage updates, and input path capture with polished prompts, fallbacks, and error handling.【F:src/autoclean/cli.py†L3038-L3258】

### 4. Expose the command in the CLI shell
We registered the `wizard` subcommand and surfaced it in the Rich help index so the new flow is discoverable from day one.【F:src/autoclean/cli.py†L640-L648】【F:src/autoclean/cli.py†L506-L514】【F:src/autoclean/cli.py†L7238-L7268】

## Considerations & follow-up

- The wizard warns if you select a built-in task (without a workspace copy) before the montage step, nudging users to create a workspace variant for safe edits.【F:src/autoclean/cli.py†L3175-L3203】
- If Rich is unavailable the command explains the missing dependency, maintaining parity with the rest of the CLI styling expectations.【F:src/autoclean/cli.py†L3038-L3047】
- You can re-run the wizard any time; it preserves completed steps and only changes what you confirm during the session.【F:src/autoclean/cli.py†L3050-L3058】【F:src/autoclean/cli.py†L3235-L3258】
