## Validation checklist

<Steps>
  ### 1. Update environment
  Install the refreshed GUI stack, or upgrade an existing environment:
  ```bash
  pip install -e .[gui]
  ```
  ### 2. Launch the exclusion GUI
  ```bash
  autocleaneeg-pipeline exclude --output /path/to/workspace/output
  ```
  The viewer should open maximized and list available `.set` files; edits save back into the run directory.
  ### 3. Legacy alias sanity check
  ```bash
  autocleaneeg-pipeline review --output /path/to/workspace/output
  ```
  Expect a console warning about deprecation before the same GUI appears.
</Steps>

## Considerations

<Callout type="warning">
QtPy selects whichever PyQt binding is available. We ship PyQt6 by default but fall back to PyQt5 if it is already installed, so double-check virtual environments that pin older Qt releases before distributing builds.【F:src/autoclean/tools/autoclean_exclude.py†L63-L88】
</Callout>
